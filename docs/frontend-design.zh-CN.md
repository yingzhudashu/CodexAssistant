# CodexAssistant 前端设计实施规格

面向 Windows Codex 工作站与 Android 手机/平板的任务进度查看、回合摘要与消息交互工具。

> 本文由 spec.json 生成，描述当前工作树。SVG为可编辑结构示意，实际验收以运行截图和测试为准。

本文与当前实现对应。CA 编号用于功能定位，同一任务详情内的分区与回执不一定是独立页面。SVG 是合成数据结构示意，不是截图或像素级复刻合同。

[图文阅读版与界面索引](frontend-design/index.html) · [结构化界面规格](frontend-design/spec.json) · [审查与验收记录](acceptance.zh-CN.md)

## 1. 权威顺序与实施范围

当前工作树为 Windows Electron 工作站和 Android Compose 手机/平板；无独立 Web、iOS 或 macOS 客户端。采用共享 Token 的单工作站模型，不存在账号切换、角色权限或通用资源删除。源码版本与发布状态见 [发布说明](release.zh-CN.md)。

同一交付中：交互表和字段规则 > 几何规范 > SVG 示例值。示例值是合成测试数据，不是默认业务数据。业务状态只取服务端或本地桥接回执；画面不允许推断业务成功。若未来协议改变，必须升级本文件与 spec.json；不得让开发者自行猜测一个静默替代行为。

## 2. 现状证据与设计差额

本轮保留任务、计划、详情、消息、交互、设置与通知，补齐清除筛选/清空草稿/复制摘要；桌面相同快照不重建 DOM，富文本改用禁用 HTML 的 markdown-it；Android 保留任务草稿、累积回执，限制详情传输缓存。后台恢复沿进程唯一 Coordinator 执行。具体通过项与未验证范围见 [验收记录](acceptance.zh-CN.md)。

## 3. 视觉、布局与组件规范

Windows 默认 1100×760、最小 430×600，原生标题栏；窄窗折叠导航，列表和详情切换。Android <600dp 单栏底部一级导航，600–839dp 使用一级 Rail 与单内容，≥840dp 列表320dp加详情双栏；二级页隐藏一级导航。系统栏与 IME 由 Insets 处理，返回先交给键盘，再返回页面。

使用项目现有蓝色主题、Segoe UI/微软雅黑或 Android 系统字体。卡片圆角12、控件8、间距以8/12/16/24为主，Android 交互区域至少48dp。深色背景#111820、表面#1B2632、正文#F1F5F9。实际 CSS/Material 排版随空间重排，SVG 画布不是运行时尺寸约束。长代码和表格内部横滚，不撑开整个页面；长文垂直滚动。实际窄窗、大字号、深浅色及键盘效果需要运行截图验证。

### 统一规则

G01：元数据、连接状态、freshness 和消息回执分开显示；缺失信息显示未提供，不能用0或已完成冒充。保留已知任务，恢复 snapshot 校准。

G02：普通消息同任务有在途请求时禁重复提交；started 仅表示 Desktop 接受。失败/超时保留草稿，旧回执不清除用户已编辑的新草稿。断网不自动重放写操作。

G03：连接编辑取消时若有修改需确认；普通任务导航保留草稿，关闭详情释放可见分页。Windows 配置保存后清空旧服务界面状态。Android 配置重建 Coordinator，旧 socket 代次失效。

G04：正文 trim 后1–20000 UTF-16代码单元；地址为 HTTPS 根地址或回环 HTTP，Token 16–4096。错误显示真实原因，不把本地保存和远端握手合成一个成功承诺。

G05：Windows Enter发送、Shift+Enter换行，IME组合时不发送；Android 多行输入用显式发送按钮。清空草稿只操作本机输入，不撤销已发送消息。

G06：回合摘要按需获取，每页20，cursor存在才继续；合并去重，旧页面响应不覆盖新页面。没有回复流或自动底部跟随承诺。Windows Markdown 安全解析；Android 文本摘要支持复制，不执行 HTML。

G07：Android 认证/协议错误停止重试；网络错误按1–6秒恢复，snapshot前禁远端发送。服务控制请求30秒、本地Android发送120秒结束未确认等待，详情30秒。Windows本机ready与云端同步分别判断。

G08：时间按设备时区格式化；Windows使用本地化日期时间，Android含UTC偏移。任务时间不随轮询伪造更新；最后采集时间另示。

G09：使用原生按钮/输入语义、焦点圈和文字状态；错误持续展示，不能只靠颜色。读屏、200%字号、系统缩放是独立验收项，未实测不得标通过。

G10：Android详情由外层消费IME padding；二级页不保留底部导航。系统返回按键盘→详情/设置子页→一级页处理。

G11：每个动作按其执行类别验证正常、不可用、重复操作和返回；图中成功与失败为分支，不是连续步骤。

G12：仅实现本合同中的功能，不引入账号注销、批量删除、文件上传、动态色或后台任务控制等无业务接口的占位按钮。

G13：local以本地状态变化完成；read以有效只读结果完成；write以匹配业务回执完成；system以安全存储/剪贴板/浏览器等实际调用完成，不推断安装或任务成功。

G14：连接修改放弃确认保留继续编辑入口；普通消息草稿不因关闭详情自动丢弃。

G15：交互请求一次提交全部必填问题，按官方schema验证，失败保留输入；秘密答案仅驻内存，不写诊断。

G16：Windows导航为任务/连接状态/外观/关于；Android一级任务/设置，设置内连接/外观/通知/关于。通知点击打开应用，任务详情从列表选择。

## 4. 状态、数据与权限合同

|域|显示与数据合同|
|---|---|
|任务状态|running进行中、completed已完成、failed失败、needs_action待确认|
|freshness|fresh近期采集、stale缓存/上次同步、unavailable无法采集；独立于网络状态|
|回合|inProgress/completed/interrupted/failed；中断不新增任务枚举|
|计划|pending/in_progress/completed/failed；无plan不显示0/0或虚构步骤|
|排序|updatedAt降序；同时间不承诺字典序|
|详情|关闭丢可见分页；Android传输层最多20个单页回执，避免无界缓存|
|消息|started/failed是发送回执；进展另读摘要，不合成回复流|
|交互|按requestId+threadId关联，多问题一次提交；只处理Monitor实际拥有的官方请求|
|身份|共享Token、一个工作站控制器；无账号角色隔离|
|工作站ready|仅采集器app-server初始化，不保证非公开Desktop发送通道可用|

## CA-01 · 首次连接

**入口与返回**：首次启动无有效凭据进入；成功进入CA-03。

**角色/设备**：尚未配置；Windows, Android。

**导航归属**：Windows沿主导航；Android一级任务/设置，二级页返回父页。具体入口见本页。

**布局**：按字段层级纵向排布，可滚动；详情用执行计划/回合摘要/发送消息分区，操作就近展示。图稿仅表示结构，实际采用原生平台组件。

**数据绑定**：`apps/desktop/src/desktop-config.ts`。Windows connection.save；Android CredentialStore/SyncCoordinator。

|---|---|---|---|
|服务地址|input|https://monitor.example.test|必填HTTPS根地址；只允许回环HTTP；拒绝用户信息/query/fragment/API子路径；去末尾斜杠|

## CA-03 · 任务首页与筛选

**入口与返回**：应用启动/底部任务/托盘打开；点击任务进入CA-04。

**角色/设备**：配置此服务的使用者（共享Token）；Windows, Android。

**导航归属**：Windows沿主导航；Android一级任务/设置，二级页返回父页。具体入口见本页。

**布局**：按字段层级纵向排布，可滚动；详情用执行计划/回合摘要/发送消息分区，操作就近展示。图稿仅表示结构，实际采用原生平台组件。

**数据绑定**：`apps/desktop/src/renderer/workspace.js`。tasks.get/onTasks或snapshot/event；过滤仅当前快照。

|控件（从上到下）|类型|图中示例|校验/显示合同|
|---|---|---|---|
|连接状态|record|已连接 · 最近同步 12秒前|连接状态独立于任务状态；显示快照同步时间|
|搜索|input|同步协调器|标题/projectName本地不区分大小写包含搜索；空值显示全部|
|状态筛选|select|全部|全部+四种协议任务状态，不添加离线/已取消到任务枚举|
|任务|record|同步协调器 · 进行中 · 2/5步骤|标题2行；状态文字；有效plan才显示进度|
|最近变化|record|部署检查 · 已完成 · 3分钟前|按updatedAt降序；时间为任务来源时间，不是轮询时间|

**页面规则**：不添加批量已读、删除任务或重试任务按钮，因为没有对应业务合同。成功空快照显示“暂无任务”；首次未收快照显示“等待首次同步”。

**空态/加载/错误**：读取时显示加载状态；失败保留已有内容并给出原因；没有数据时明确说明。纯设置与本地操作不显示伪造的远端加载或列表空态。

## 6. 平台与系统级行为

Windows关闭窗口继续托盘采集，双击托盘恢复，右键菜单打开/退出；退出等待队列和子进程收尾。Android唯一前台同步服务，低重要性常驻通知与任务变化通知分渠道，系统决定权限和后台限制。更新读取清单后交给系统浏览器，不在应用中模拟安装进度。独立app-server不能代答Desktop自己的审批。
